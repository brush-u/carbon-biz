# 시도 경계 — 구역을 눌러 그 지역만 보기

## 왜 타일만으로는 안 되는가

OpenStreetMap 타일에 행정경계가 그려져 있는 건 맞습니다. 다만 그건 **그림**입니다.
타일은 256×256 PNG 조각이고, 그 안의 선은 픽셀일 뿐 "여기부터 경기도"라는 정보가 없습니다.
브라우저는 어느 픽셀을 눌렀는지만 알지, 그 픽셀이 어느 행정구역인지 모릅니다.

구역을 눌러 필터하려면 **좌표로 된 경계 폴리곤**이 따로 있어야 합니다.
그걸 만드는 게 `9_boundary.py` 이고, 결과는 `cache\boundary.json` (144KB, 시도 17개, 폴리곤 79개)입니다.

```powershell
python src\10_boundary.py
python src\09_page.py
Copy-Item map_page.html index.html -Force
```

## 경계를 어디서 가져왔나

`vendor\sido_svg.json` — [MapSVG](https://mapsvg.com/maps/south-korea)의 대한민국 지도,
**CC BY 4.0** (상업적 사용 가능, 출처 표시 필요)입니다. 폴더에 동봉해 뒀으니 내려받을 게 없습니다.

문제는 이게 **SVG 좌표계**(0 0 524 631)라는 것이었습니다. 위경도가 아니라 그림 안의 픽셀 좌표입니다.
지도의 투영법이 무엇인지 문서에 없어서, 변환식을 추측하는 대신 이렇게 맞췄습니다.

> **지오코딩된 공장 10,220곳**은 좌표와 시도 라벨을 둘 다 알고 있습니다.
> "각 공장이 제 시도 폴리곤 안에 들어가도록" 아핀 변환 6개 값을 최적화했습니다.

정답을 아는 점 1만 개에 지도를 끼워 맞춘 셈입니다. 결과:

| 기준 | 비율 |
|---|---|
| 폴리곤 안에 정확히 들어감 | 91.2% |
| 1km 이내 | 97.7% |
| 3km 이내 | 99.4% |

남은 오차는 대부분 원본 지도의 단순화 때문입니다. 해안선이 뭉뚱그려져 있고 작은 섬이 빠져 있어
바닷가 공장이 몇백 미터 밖으로 나갑니다. 세종처럼 작고 경계가 복잡한 곳이 가장 나쁩니다.

**행정 목적으로 쓸 정확도는 아닙니다.** 구역을 눌러 걸러 보는 용도입니다.

## 더 정확한 경계로 바꾸려면

VWorld의 `LT_C_ADSIDO_INFO`처럼 위경도로 된 공식 경계 GeoJSON을 구했다면,
`boundary\` 폴더에 넣기만 하면 그쪽을 먼저 씁니다.

```

└─ boundary\
   └─ sido.geojson      ← 여기 넣으면 SVG 대신 이걸 씁니다
```

```powershell
python src\10_boundary.py     # boundary\*.geojson 을 먼저 찾습니다
```

시도명 컬럼은 `ctp_kor_nm`, `CTP_KOR_NM`, `name`, `sido_nm` 중 아무거나면 되고,
`경기도`·`경기`·`충청북도` 어느 표기든 알아서 짧은 이름으로 맞춥니다.
좌표계는 **EPSG:4326 (위경도)** 여야 합니다. 좌표가 백만 단위 숫자면 EPSG:5179 등
평면직각좌표라 먼저 변환해야 합니다.

바꾼 뒤에는 반드시 검증 줄을 보십시오.

```
  검증 — 공장 10,220곳 중 99.6%가 제 시도 폴리곤 안
```

85% 미만이면 좌표계가 어긋난 것입니다. `6_test.py`도 같은 것을 검사합니다.

## 화면에서 달라지는 것

| 위치 | 달라지는 것 |
|---|---|
| 지도 | 시도 구역이 그려지고, **진할수록 타깃이 많은 곳**입니다 |
| 지도 클릭 | 구역을 누르면 그 시도만 남습니다. 다시 누르면 풀립니다 |
| 지도 hover | 시도명과 현재 필터 기준 타깃 건수가 뜹니다 |
| 폴백 화면 | 배경지도를 못 받는 사내망에서도 같은 경계가 SVG로 그려집니다 |
| 시도별 구성 막대 | 지도 클릭과 서로 연동됩니다 |

경계 파일이 없으면 예전처럼 격자 위 버블로 그리고, 나머지는 그대로 동작합니다.

## 같이 고친 것 — 지도의 점이 검게 나오던 문제

Leaflet은 점이 많으면 canvas로 그립니다. 그런데 **canvas의 `fillStyle`은 CSS 변수를 못 읽습니다.**
`var(--s1)` 같은 값을 넘기면 무시하고 검정으로 칠합니다. 업종별로 색을 준 게 전부 검게 나온 이유입니다.
이제 실제 색값으로 풀어서 넘기므로 업종 색이 제대로 나옵니다.
