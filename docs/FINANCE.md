# 회사 규모(매출) 붙이기

## 기대치를 먼저 맞춰야 합니다

**공장 21만 곳 대부분은 매출이 어디에도 공개되지 않습니다.** 공시 의무가 없기 때문입니다.
공개되는 곳은 금융감독원 전자공시(DART)에 **정기보고서를 내는 법인** — 상장사와 일부 대형
비상장사뿐입니다. 이름이 맞아떨어져 매출이 붙는 비율은 **한 자릿수 퍼센트**입니다. 그게 정상입니다.

나머지를 알려면 NICE평가정보·한국기업데이터·이크레더블 같은 **유료 기업정보 DB**를 사야 합니다.
사업자등록번호가 원본에 없어 그쪽도 결국 상호+주소로 맞춰야 합니다.

붙는 값은 **법인 단위**입니다. 공장 한 곳의 매출이 아닙니다. 한 법인에 공장이 열 곳이면
열 줄에 같은 매출이 붙습니다. 화면에서도 법인명을 함께 적어 그 점을 드러냈습니다.

---

## 인증키 받기

1. https://opendart.fss.or.kr → 우측 상단 **인증키 신청/관리**
2. 이메일 인증 후 즉시 발급 (무료, 40자리)
3. 하루 20,000회까지 호출할 수 있습니다

## 실행

```powershell
cd D:\workspace\carbon-biz
python src\05_finance.py --key 발급받은키 --limit 50     # 먼저 50건 시험
python src\05_finance.py --key 발급받은키                # 전체
```

처음 한 번은 DART 고유번호 목록(약 20MB)을 받아 `finance\corpcode.xml`에 둡니다. 이후 재사용합니다.

```
  DART 고유번호 110,432개
  공장 회사명 171,446개 중 4,318개가 DART 법인과 이름이 맞습니다 (법인 2,905개)
  조회 대상 2,905건 (캐시 0건 재사용) · 2025년 사업보고서
     100/2,905  확보 78  없음 22  14s
```

**중간에 끊어도 됩니다.** `fin_cache.json`에 남으므로 다시 실행하면 이어서 합니다.
일일 한도(20,000회)에 걸리면 다음 날 이어서 하면 됩니다.

이어서 페이지를 다시 만듭니다.

```powershell

Copy-Item map_page.html index.html -Force
```

## 결과 확인

`재무_매칭결과.csv`를 엑셀로 열어 **엉뚱하게 붙은 것이 없는지 30줄쯤 보십시오.**

이름 대조 규칙은 `8_emission.py`와 같습니다 — 법인 표기(`(주)`·`주식회사`)와 공장 꼬리표
(`제1공장`)를 지운 뒤, 정확히 같거나 **띄어쓰기·`(주)` 자리에서 끊긴 경계**에서만 붙입니다.
그래야 `포스코케미칼`이 `포스코`에 붙어 69조가 엉뚱한 법인에 찍히는 일이 없습니다.

그래도 동명이인 법인은 남습니다. 특히 짧고 흔한 상호(`대성`, `동방`, `삼진`)가 위험합니다.

## 화면에서 달라지는 것

| 위치 | 달라지는 것 |
|---|---|
| 공장 목록 | **매출액** 열이 생깁니다 (조·억 단위) · 상장사는 `상장` 표시 |
| 지도 팝업 | 점을 누르면 매출과 법인명이 같이 뜹니다 |
| 회사명 메뉴 | 회사명을 누르면 뜨는 창 머리에 매출이 붙습니다 |
| 목록 위 안내 | 몇 곳 중 몇 곳에 붙었는지 비율을 적어둡니다 |

파일이 없으면 매출 열은 나오지 않고 나머지는 그대로 동작합니다.

## 쓰이는 API

| 용도 | 엔드포인트 |
|---|---|
| 고유번호 목록 | `corpCode.xml` — 전체 법인의 8자리 코드 |
| 재무 | `fnlttSinglAcnt.json` — 사업보고서(`reprt_code=11011`) 주요계정 |

가져오는 계정은 **매출액 · 영업이익 · 당기순이익 · 자산총계**이고,
연결재무제표(CFS)가 있으면 그쪽을, 없으면 개별(OFS)을 씁니다.
