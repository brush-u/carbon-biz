# 배출량 데이터 붙이기

## 먼저 — 업체 상세정보는 공개된 게 거의 없습니다

전국등록공장현황에는 회사명·생산품·주소·단지명 다섯 칸이 전부입니다.
**사업자등록번호가 없어** 다른 공공데이터와 기계적으로 이어붙일 수 없습니다.
연락처·홈페이지·종업원수·매출은 어느 공개 데이터셋에도 없습니다.
NICE평가정보·한국기업데이터 같은 민간 기업정보를 사야 붙습니다.

이름으로 이을 수 있는 공개 데이터는 사실상 배출량 계열 둘입니다.

| 데이터 | 건수 | 무엇이 들어 있나 | 주소 |
|---|---|---|---|
| **할당대상업체 현황** | 2,030 | 업체명 · 주소 · 업종 · 지정연도 · 계획기간 | [data.go.kr/data/15053949](https://www.data.go.kr/data/15053949/fileData.do) |
| **관리업체 명세서 배출량** | 10,557 | 법인명 · 배출량(tCO₂eq) · 에너지사용량(TJ) · 지정업종 · 관장기관 · 연도 | [data.go.kr/data/15053947](https://www.data.go.kr/data/15053947/fileData.do) |

두 파일 모두 **법인 단위**입니다. 사업장별 배출량은 공개되지 않습니다.
온실가스종합정보센터 [명세서 배출량 통계](https://www.gir.go.kr/home/index.do?menuId=37)에서
연도별로 화면 조회와 엑셀 내려받기도 됩니다 (2011~2025년).

참고로 볼 만한 것들 — 공장 목록에 붙지는 않습니다.

- [화학물질 배출·이동량(PRTR)](https://icis.me.go.kr/prtr) — 사업장 단위. 온실가스가 아니라 화학물질
- [국가·지역 온실가스 통계](https://www.gir.go.kr/home/index.do?menuId=36) — 시도별 인벤토리
- [국가 온실가스 인벤토리 배출량](https://www.data.go.kr/data/15049589/fileData.do) — 부문·업종 단위

## 붙이는 순서

### 1. 두 파일 받기

위 표의 두 주소에서 **내려받기** 를 누릅니다. 로그인이 필요합니다.
받은 파일을 `data\emission\` 폴더에 그대로 넣습니다. 이름은 바꾸지 않아도 됩니다.

```

└─ emission\
   ├─ ..._할당대상업체 현황_20240226.xlsx
   └─ ..._관리업체 명세서 배출량_20230926.xlsx
```

`*할당대상업체*` / `*명세서*` 패턴으로 찾으니 파일명에 그 말만 들어 있으면 됩니다.
연도마다 헤더가 조금씩 바뀌는데, 컬럼을 이름으로 고정하지 않고 키워드로 찾으므로
대개는 그대로 읽힙니다. 못 찾으면 실제 컬럼 목록을 찍어주니 알려주십시오.

**파일 형식이 이름과 다릅니다.** 공공데이터포털이 "XLS"라고 표시해도 실제 알맹이는
셋 중 하나입니다. 확장자를 믿지 않고 파일 앞머리를 보고 판별합니다.

| 앞머리 | 실제 형식 | 읽는 방법 |
|---|---|---|
| `PK..` | 진짜 xlsx | openpyxl (이미 설치됨) |
| `D0 CF 11 E0` | 옛 xls 이진 | **xlrd 필요** |
| 그 밖 | HTML 표 또는 CSV인데 이름만 .xls | 자동 처리 |

옛 xls가 걸리면 이렇게 나옵니다.

```
이 파일은 옛 xls 형식이라 xlrd 가 있어야 읽힙니다.
  pip install xlrd
```

`pip install xlrd` 한 번이면 끝입니다. xlrd 2.x가 .xls 전용이라 이 용도에 맞습니다.
사내망에서 pip가 막히면 엑셀로 열어 **다른 이름으로 저장 → CSV UTF-8** 로 바꿔 넣어도 됩니다.

위쪽에 안내 문구가 몇 줄 붙어 헤더가 3~4행부터 시작하는 파일도 있는데,
0~5행을 훑어 업체명 컬럼이 잡히는 행을 헤더로 씁니다.

### 3. 매칭 결과를 반드시 훑어보기

`배출량_매칭결과.csv` 에 붙은 이름 쌍이 전부 들어 있습니다.
**엑셀로 열어 30줄 정도는 눈으로 보십시오.**

양쪽에 사업자등록번호가 없어 **이름 대조가 유일한 방법**입니다. 그래서 이렇게 맞춥니다.

1. 법인 표기를 지웁니다 — `주식회사 포스코`, `(주)포스코`, `㈜포스코` → `포스코`
2. 공장 꼬리표를 지웁니다 — `현대제철(주)제1공장` → `현대제철`
3. 남은 이름이 정확히 같으면 붙입니다
4. 정확히 같지 않으면, **띄어쓰기나 `(주)` 자리에서 끊긴 경계**에서만 접두 일치를 봅니다

4번의 경계 조건이 중요합니다. 그냥 접두 일치를 허용하면 `포스코케미칼`이 `포스코`에 붙어
포스코의 7,512만 톤이 엉뚱한 법인에 찍힙니다. 경계를 요구하면
`쌍용씨앤이(주)동해공장`은 `쌍용씨앤이`에 붙고 `포스코케미칼`은 안 붙습니다.

그래도 완벽하지 않습니다. 동명이인 법인, 사명 변경, 지주사와 자회사가 섞입니다.

## 화면에서 달라지는 것

| 위치 | 달라지는 것 |
|---|---|
| 조회조건 | **규제** 줄이 생깁니다 — `할당대상` / `명세서 제출` / `규제 밖` |
| 기업 목록 | **배출량** 열이 생깁니다. 법인 단위 값이라 법인명을 함께 표시합니다 |
| 배출량으로 본 자리 | 네 번째 카드에 규제 안/밖 건수가 채워집니다 |

파일이 없으면 규제 줄과 배출량 열은 나오지 않고, 나머지는 그대로 동작합니다.

## 숫자를 읽을 때

**배출량은 법인 값이지 공장 값이 아닙니다.** 한 법인에 공장이 열 곳이면 열 줄에 같은
값이 붙습니다. 합계를 내면 열 배가 됩니다. 그래서 화면에서도 `○○ 전체` 라고 적어뒀습니다.

**규제 문턱** — 이 사업의 대상이 어디인지를 정하는 선입니다.

| 제도 | 업체 단위 | 사업장 단위 | 대상 수 |
|---|---|---|---|
| 배출권거래제 | 125,000 tCO₂eq | 25,000 tCO₂eq | 할당대상업체 2,030건 공개 |
| 목표관리제 | 50,000 tCO₂eq | 15,000 tCO₂eq | 348개 (2025-06-30 고시) |

배출권거래제는 최근 3년 연평균 기준이고, 3,000 tCO₂eq 이상이면 자발적으로 참여할 수 있습니다.

**이 문턱 아래가 우리 대상입니다.** 규제를 받지 않으니 배출량을 세어본 적이 없고,
그래서 CBAM 신고서를 쓸 수 없습니다. 지도에서 `규제 밖` 칩을 누르면 그 집합만 남습니다.

**국가 수치와 견주려면** (2024년 잠정, 2006 IPCC 기준)

- 총배출 691.6백만 tCO₂eq (전년 대비 2% 감소)
- 산업 부문 285.9 / 전환·발전 218.3 / 수송 97.5 / 건물 43.6
