# Google My Maps에 핀 꽂기

`mymaps/` 폴더의 CSV를 My Maps에 올리면 됩니다.
**좌표가 없어도 My Maps가 주소 열을 보고 알아서 위치를 찍습니다** — VWorld 지오코딩을 안 해도 됩니다.

## 제한 먼저

| 항목 | 한도 |
|---|---|
| 파일당 행 수 | **2,000행** (그래서 1,900행씩 잘라뒀습니다) |
| 지도당 레이어 | **10개** |
| 파일 크기 | CSV 40MB / KML 5MB |

10개 레이어가 상한이라 **전부 올릴 수는 없습니다.** 목적에 맞게 골라야 합니다.

## 만드는 순서

1. https://mymaps.google.com 접속 → `새 지도 만들기`
2. 왼쪽 패널에서 `가져오기` 클릭
3. CSV 파일 선택 (드래그해도 됩니다)
4. **위치 열 선택** — 아래 표의 "위치 열"에 해당하는 것을 체크
5. **마커 제목 열 선택** — `이름`
6. 레이어 이름을 알아보기 쉽게 바꾸기 (예: "산단공 거점")
7. 레이어별로 2~6 반복

## 권장 조합 (10 레이어 안에서)

**A안 — 전국 조망용**

```
1  산단공 거점 (14)
2  국가산업단지 (38)
3  주요 일반산업단지 (300)
4  농공단지 (447)
5  도시첨단·자유무역·외투 (47)
6~8  용해_소성 01~03 (3,839)
```

거점·단지 유형이 한눈에 들어오고, 고온 열공정 공장이 어디 몰려 있는지 겹쳐 보입니다.
레이어 2개가 남으니 관심 업종을 더 올릴 수 있습니다.

**B안 — CBAM 집중**

```
1  산단공 거점 (14)
2  국가산업단지 (38)
3~10  타깃_전체 01~08 (15,200)
```

## 도드라지게 보이도록 — 스타일 설정

**핀을 눈에 띄게 하려면** 레이어 이름 아래 `개별 스타일` → `균일 스타일`로 바꾸고
페인트통 아이콘에서 색과 아이콘을 지정합니다.

| 레이어 | 권장 |
|---|---|
| 산단공 거점 | **빨강 · 큰 별 아이콘** — 가장 눈에 띄게 |
| 국가산업단지 | **파랑 · 공장 아이콘** |
| 일반산업단지 | 하늘색 · 작은 원 |
| 농공단지 | 초록 · 작은 원 |
| 공장 (타깃) | 회색 또는 주황 작은 점 |

거점과 국가산단을 위쪽 레이어로 올리면(레이어를 드래그) 공장 점 위에 겹쳐 그려집니다.

**단지 유형별로 색을 자동 지정하려면** — 여러 단지 유형이 한 파일에 있을 때
`개별 스타일` → `다음 기준으로 그룹화` → `단지유형` 을 고르면 유형별로 색이 갈립니다.

## 알아둘 것

- **주소 지오코딩 실패** — My Maps가 못 찾은 행은 가져오기 후 "위치를 찾을 수 없음"으로 표시됩니다.
  공장 주소에 "외 1필지", "3층 202호" 같은 꼬리표가 붙어 있어 일부는 실패합니다.
  실패가 많으면 `2_geocode.py`로 좌표를 먼저 만든 뒤 `위도`·`경도` 열로 올리는 편이 정확합니다.
- **산업단지 위치** — 단지는 주소가 없어 `시도 + 시군구 + 단지명`을 검색어로 넣었습니다.
  구글이 장소명으로 찾으므로 대부분 맞지만, 이름이 특이한 단지는 시군구 중심에 찍힐 수 있습니다.
- **산단공 주소** — 2026년 7월 광주·전남이 전남광주통합특별시로 통합됐습니다.
  지오코딩 안정성을 위해 도로명주소는 통합 이전 시도명으로 적고 비고에 남겨뒀습니다.
- 업종·열공정은 생산품 텍스트에서 **추정**한 값입니다. 확정 분류가 아닙니다.
